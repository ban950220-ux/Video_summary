# 7·8단계 설계 (2026-11-21, 사용자 확인 대기)

## 8단계 — 상세 분석과 숫자 근거 검증

### 목표
1차 결과(핵심 결론 + 챕터) 다음 단계로 **주장·인과·맥락**을 정리한다. 요약과 분석에 나온 **모든 숫자**는 원문과 대조해 표시한다(숫자 검증 설계 `NUMERIC_VERIFICATION_DESIGN.md`, 승인됨).

### 8-A. 숫자 근거 검증 (먼저 구현, 모델 호출 없음)
- 승인된 설계대로 구현한다: 누락, 구간, 인용, 값, 한정어, 지표 검사. 결과는 숫자마다 ✓ / ⚠ / ? 로 표시한다.
- 이미 저장된 요약에도 **추가 비용 없이** 적용된다. 3단계부터 facts가 포함되어 있기 때문이다.
- 운영 중인 3건(facts 32·40·36개)에 실제로 돌려 판정 가능 비율과 오판을 측정한다.
- 완료 기준: 숫자 검증 설계 5장(회귀 사례 전부 통과, 실제 영상에서 판정 가능 80% 이상, 무작위 20개 중 오판 2개 이하).
- 불일치 항목 1회 자동 재생성은 측정 결과를 본 뒤 결정한다(무료 호출을 쓰므로).

### 8-B. 상세 분석 (모델 호출, 버튼으로 실행)
- 결과 화면에 **"상세 분석 만들기"** 버튼을 둔다. 자동 실행하지 않는 이유는 무료 한도를 아끼기 위해서다. 2시간 영상이면 요약과 비슷하게 약 14회 호출된다.
- 출력(구간 근거 필수, 화자 진술과 AI 해석 구분):
  | 항목 | 내용 |
  |---|---|
  | 주장 | 화자의 주장, 근거·이유, 조건·예외, 영상 안의 반론 |
  | 인과 | 원인 → 결과, 화자가 말한 것인지 AI가 추론한 것인지 표시 |
  | 맥락 | 전제, 비교 기준, 기간·분모 등 숫자 해석에 필요한 정보 |
  | 불확실성 | 예측·가정·완곡 표현을 사실과 구분해 표시 |
- 외부 사실 확인은 하지 않는다. 영상 내용만 근거로 쓴다.
- 숫자 검증(8-A)을 분석 결과에도 똑같이 적용한다.
- 완료 기준: 2시간 가짜 전사 테스트 통과. 실제 영상 1건에서 분석 생성(DONE), 구간 근거 존재율 100%, 숫자 검증 표시.

## 7단계 — PC 실행기 (사용자 PC 필요)

### 목표
자막이 없고 Gemini도 처리하지 못한 영상, 또는 소유한 음성 파일을 **사용자 PC에서 전사**해 v1에 넘긴다. 클라우드는 계속 무료 범위만 쓴다.

### 동작
1. 화면에서 "PC 실행기로 처리"를 누르면 작업이 `PC 대기` 상태가 된다.
2. PC 실행기(`node scripts/v1-pc-runner.mjs`)가 대기 작업을 가져온다.
3. 처리 과정:
   1. yt-dlp로 음성을 받는다.
   2. ffmpeg로 16kHz 모노 MP3로 바꾼다.
   3. 구간을 나눈다(기존 `scripts/local-*` 재사용).
   4. 전사한다.
   5. v1에 전사를 올린다.
4. 이후 요약은 지금과 같은 클라우드 파이프라인이 처리한다.

### 전사 방법(선택)
- **Groq Whisper (무료 API)**: 빠르다. 무료 한도는 시간당·일일 음성 길이 제한이 있다(착수 시 콘솔 수치 확인).
- **PC 로컬 Whisper**: 한도가 없지만 PC 성능에 따라 느리다.

### 인증
- PC용 **별도 Access 서비스 토큰**을 쓴다. 이 토큰은 실행기 API(`/api/v1/runner/*`)만 열린다.
- 토큰 Secret은 PC의 환경 변수로만 둔다. 저장소에 넣지 않는다.

### 사용자 PC에 필요한 것
- Node 24, yt-dlp, ffmpeg (인계 기록상 ffmpeg 실행 권한 문제가 있었음)
- 서비스 토큰 하나 추가 생성
- 실행기를 켜 두기(필요할 때만 실행해도 됨)

### 주의
- **YouTube 영상 음성을 내려받는 것은 YouTube 이용약관에 걸릴 수 있다.** 사용자가 권리를 가진 영상이나 개인 학습용 등 사용자 판단 범위에서만 쓰도록 화면에 안내하고, 실행 전에 확인을 받는다(인계 문서 원칙).

### 완료 기준
- 단위 테스트(작업 가져오기, 중복 방지, 업로드 검증) 통과
- 사용자 PC에서 실제 영상 1건: PC 대기 → 전사 업로드 → v1 요약 DONE

## 진행 순서 제안

1. 9번 배포·실검증
2. 8-A 숫자 검증: 비용이 없고 바로 측정할 수 있다
3. 8-B 상세 분석
4. 7단계 PC 실행기: 사용자 PC 준비와 함께
